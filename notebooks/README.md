# Notebooks

IC103 has no notebooks, so this folder is empty apart from this file; it's left from the course template. What students run is in `labs/`: the shared checks in `labs/common/` and each lab's own scripts in `labs/<lab-id>/src/`.

If a notebook is added later, strip heavy outputs before you commit it (`.gitignore` already ignores `.ipynb_checkpoints/`), and keep anything a lab depends on in that lab's package under `labs/<lab-id>/` instead.
